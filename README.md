# PE-parser-manual-in-c

# SOBRE ESTE PROJETO

    É um projeto para estudos com o objetivo de entender o conceito de um PE parser mais afundo
    Este em especifico, eu não fui tão profundo, então ele não é um PE parser completo como os que são usados no mercado.

# O QUE É UM PE PARSER

    O PE parser é uma ferramenta que analisa uma estrutura interna no formato de portable executable, Normalmente sendo eles um ".exe" ou ".dll"

# O QUE ELE FAZ?

    Com ele, voce pode ler Headers, sections, e tabelas de importação e exportação

# PARA QUE ELE É USADO?

    Ele normalmente é usado para analises de malware, engenharia Reversa e etc.

# COMO RODA-LO?

    Primeiro voce deve criar um .exe do arquivo C
    Em seguido um .o
    E por fim um .dll

# SAIDO ESPERADA

    A saida esperada seria algumas strings como: "/19", ".rdata", ".text"
